2. VLAN isolation, trunks, router-on-a-stick, inter-VLAN routing
3. STP/RSTP and EtherChannel
4. DHCP, DNS, HTTP, FTP, email, NAT/PAT, ACLs
5. OSPF neighbor state machine and SPF calculation
6. RIP, EIGRP, BGP
7. IPv6, NDP, SLAAC, DHCPv6
8. Wireless association, SSIDs, security, roaming
9. Physical modules and cable compatibility
10. Simulation filters, packet inspection, activities, grading, hints, certificates
